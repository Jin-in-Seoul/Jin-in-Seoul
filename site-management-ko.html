운영 및 관리

English · 한국어

Jin-in-Seoul은 문학 작품과 번역판을 독립적인 HTML 파일로 보존한다. 관리 문서는 보존, 편집, 번역, 출판 및 기술 관리의 원칙을 기록하여 작품과 사이트 운영이 특정 소프트웨어나 관리자에게 종속되지 않도록 한다.

아래 공통 관리 문서 7개는 GitHub 저장소의 한국어 관리 문서에서 직접 변환한 것이다. 작품별 번역 가이드는 향후 번역을 위해 저장소에 보존한다.

목차
  1. ABC — 사이트 운영 및 관리 규정
  2. README — 전체 관리 체계
  3. CSS 관리
  4. SEO 관리
  5. 자산 관리
  6. 발행 기록 규정
  7. 한국 고전소설 번역 및 편집 원칙
